# OperDirCLODEmirzap

ИИ-система управления компанией: рабочий стол руководителей, показатели, задачи Битрикс24, интеграции, ИИ-чат и агенты. Полное описание: ТЗ (документ в Claude).

## Что уже работает (этап 1, каркас)

- Вход по email и паролю, сотрудники и роли (владелец / сотрудник, право применять доработки).
- Рабочий стол: окна, панель задач, чат слева с изменяемой шириной.
- Раздел «Интеграции»: статус каждого источника, время последней проверки и последней выгрузки данных. Проверка запускается при старте и затем раз в час (`INTEGRATION_CHECK_MINUTES`), плюс кнопки ручной проверки.
- ИИ-чат через заменяемый слой модели (`backend/app/llm.py`). Без `ANTHROPIC_API_KEY` чат честно сообщает, что ИИ не подключён.
- Остальные разделы пока заглушки; порядок работ в ТЗ.

Раздел «Файлы»: папки, загрузка и скачивание; папку можно привязать к источнику данных (например, 1С), тогда загрузка файла отмечает свежую выгрузку. Подключения компании и сотрудников (Telegram, почта, таблицы по ссылке, Диск, FTP) в окне «Интеграции».

Что ещё не сделано: разбор данных (РНП, 1С, Битрикс24, Метрика), агенты, бот Телемоста. Проверки интеграций для них уже есть и покажут «Не настроено» или «Ошибка», пока источники не подключены. Проверки Google Sheets, Метрики, Вебмастера и API модели с реальными ключами ещё не прогонялись.

## Запуск на сервере

Подробная инструкция для разработчиков (сервер, HTTPS, автовыкладка, резервные копии): [docs/DEPLOY.md](docs/DEPLOY.md). Ниже краткая версия.

Нужны Docker и Docker Compose.

```bash
cp .env.example .env
# заполните SECRET_KEY, POSTGRES_PASSWORD, ADMIN_EMAIL, ADMIN_PASSWORD
mkdir -p secrets
docker compose up -d --build
```

Сайт откроется на порту `HTTP_PORT` (по умолчанию 80). Войти можно под `ADMIN_EMAIL` / `ADMIN_PASSWORD`: владелец создаётся при первом запуске, если в базе нет пользователей. В `prod` система не стартует без надёжного `SECRET_KEY`.

Сайт отдаётся по HTTP. Для работы через интернет поставьте перед ним HTTPS (например, Caddy или Nginx с сертификатом), иначе пароли пойдут открытым текстом.

## Разработка локально

```bash
# бэкенд (SQLite, без Docker)
cd backend && pip install -r requirements.txt
ADMIN_EMAIL=me@example.com ADMIN_PASSWORD=change-this-pass uvicorn app.main:app --reload
python -m pytest

# фронтенд
cd frontend && npm install && npm run dev   # http://localhost:5173, /api проксируется на :8000
```

## Структура

- `backend/app` — FastAPI: `routers/` (API), `integrations/` (реестр и проверки), `llm.py` (слой модели), `scheduler.py` (часовые проверки).
- `frontend/src` — React + TypeScript: `components/Desktop.tsx` (рабочий стол), `components/apps/` (окна разделов).
- `docker-compose.yml` — база, бэкенд, фронтенд с nginx.
