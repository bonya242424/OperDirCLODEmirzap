# Карта пользовательских путей

Принципы: один экран — одна задача; всё важное видно без поиска; любое действие обратимо или просит подтверждения; цвет только для смысла (красный — беда, жёлтый — внимание, зелёный — норма); у каждого экрана есть состояния «загрузка», «пусто», «ошибка» с подсказкой, что делать; всё доступно с клавиатуры.

Допущение: «ЛК» — это агент по возвратам, который работает в личных кабинетах поставщиков (экран «Агенты»).

## 1. Добавить задачу
Цель: завести задачу за 5 секунд, а подробности добавить позже.

| Шаг | Что видит человек | Что делает | Результат |
|---|---|---|---|
| 1 | Канбан, в каждой колонке «+ Добавить» | Нажимает «+ Добавить» или кнопку «Новая задача» (или клавишу N) | В колонке появляется строка ввода |
| 2 | Поле «Название задачи, Enter» | Пишет название, Enter | Карточка сразу в колонке, поле готово для следующей |
| 3 | Карточка в колонке | Нажимает на неё | Справа открывается панель задачи |
| 4 | Панель: исполнитель, срок, приоритет, описание | Дополняет «Изменить» | Сохранено, панель обновилась |

Ошибки: пустое название — поле закрывается без создания; сеть упала — красная строка над доской, текст не теряется.

## 2. Просмотреть задачу
Цель: понять, что делать, кто связан и спросить агента, не уходя с доски.

Панель справа (доска остаётся видна):
1. Шапка: статус, «просрочена», название, исполнитель, срок, источник (Битрикс24).
2. Описание.
3. Связанные задачи: родительская, подзадачи, из того же проекта. Клик открывает их тут же.
4. Чат с агентом по задаче: он видит задачу и связанные, помнит переписку, не меняет ничего сам.
5. Закрыть: крестик или Esc.

Задачи из Битрикс24 приходят по каждому сотруднику, фильтр «Все / Мои / конкретный сотрудник».

## 3. Агент по возвратам в ЛК поставщиков
Цель: владелец запускает под контролем, видит каждый шаг, может остановить.

Путь: Агенты → «Возвраты поставщику» → выбрать поставщика → проверить список позиций → «Запустить» → смотреть ход → подтвердить необратимые шаги → отчёт.

Экран состоит из трёх частей: слева поставщики и очередь; в центре живой ход работы (шаги, статус каждого); справа подтверждения и журнал. Кнопка «Остановить» всегда на виду. Перед отправкой заявки агент останавливается и ждёт «Подтвердить». Первый запуск идёт только на одном поставщике.

## 4. Интеграции
Цель: за 3 секунды понять, что работает, что сломано и что делать.

Шапка со сводкой (работают / внимание / не настроены), вкладки «Системы» и «Подключения», у каждой системы цвет, время последней проверки и подсказка, как починить. Кнопка «Проверить» на каждой и «Проверить все».

## 5. Дашборды директоров
Цель: сначала самое плохое.

Плитки отсортированы по тяжести (красные, жёлтые, зелёные), на плитке значение, изменение «к предыдущему», мини-график. Клик открывает ящик с историей и настройкой порогов. Пустой показатель — приглашение внести первое значение.

## 6. Общее
Окна: перетаскиваются, один клик по доку открывает и фокусирует. Esc закрывает панель. Тема день/ночь сохраняется. Узкий экран 1024 px без горизонтальной прокрутки.
