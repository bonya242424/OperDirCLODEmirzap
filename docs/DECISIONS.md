# Договорённости с владельцем

## Подход
- Одна система вместо набора сервисов. n8n не ставим: агенты решают сами по поручению и набору инструментов.
- Все видят всё, пока не решено иначе. У компании и у каждого сотрудника свои подключения.
- Агент работает в рамках доступов создавшего его сотрудника. Перед необратимым действием просит подтверждение. Владелец видит журнал всех запусков.

## Интеграции
- 1С (Бухгалтерия и старая УТ): только файлами в раздел «Файлы», обмена нет.
- Google Таблицы: по ссылкам с открытым доступом, без сервисного аккаунта.
- Почта: свой почтовый сервер по IMAP, данные позже. FTP: данные позже.
- Диадок: в бэклоге, для бухгалтера. Mirzap MCP: ещё не существует.
- Битрикс24: задачи читаем по сотрудникам (вебхук). Нужно решить: отправлять ли наши задачи в Битрикс24.
- Запросы к ИИ идут через список прокси (раздел «Мой кабинет → Прокси»).

## Агенты
- Три уровня: руководитель (ставит задачи через промт), аналитик (анализирует и делает выводы), опер-штаб (по расписанию собирает данные и показатели).
- Агент определяется поручением и набором инструментов, а не жёстким сценарием.
- Первый боевой сценарий: возвраты поставщикам в личных кабинетах. Приоритет выше записи встреч.
- Первый поставщик Армтек (etp.armtek.ru). Таблица возвратов: колонки Товар, Наименование, Производитель, Кол. по документу, Начальный склад возврата, Дата счёта, Номер счета, причина возврата. Одна заявка на счёт. Адрес и контакт на сайте подставляются сами, фото и акт не нужны. Если счёт не найден или количество не сходится, агент спрашивает владельца.
- Вход в кабинеты поставщиков выполняет человек, агент пароли не вводит.
- Агент встреч: заходит в Телемост по ссылке, говорит голосом, пишет и расшифровывает все встречи, делает резюме, предлагает задачи (создаются после подтверждения человеком), использует память встреч. Цифры только из базы.

## Открытые вопросы
- Где работает браузер возвратов: Chrome владельца или браузер на сервере.
- Что делать при отклонении заявки сайтом.
- Пример выгрузки 1С по заказам для опер-штаба.
- Токен Telegram-бота и chat id для утренней сводки.
- Миграции базы (Alembic) перед первым обновлением схемы на проде.
